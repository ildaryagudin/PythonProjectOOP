## Описание
Описание основных сущностей и инициализации объектов

Cздаys новые классы Smartphone и LawnGrass, которые наследуют 
базовые характеристики от общего класса Product. Эти новые классы 
получили дополнительные специфичные поля, соответствующие 
характеристикам смартфона и травы соответственно.

Реализация множественного наследования
В данном проекте реализовано множественное наследование для создания гибкой и расширяемой архитектуры классов:

Mixin-класс MixinLogCreation:

Служит для добавления функциональности логирования создания объектов
Наследуется первым в цепочке MRO (Method Resolution Order)
Переопределяет метод __repr__ для вывода информации о создании объекта
В конструкторе выводит подробную информацию о передаваемых аргументах

Базовый класс Product:

Наследует функциональность от MixinLogCreation
Содержит основную бизнес-логику для работы с товарами
Реализует свойства (property) для контроля цены
Определяет методы __str__ и __add__ для строкового представления и сложения товаров

Специализированные классы Smartphone и LawnGrass:

Наследуются от Product, получая всю его функциональность
Добавляют специфичные атрибуты для соответствующих типов товаров
Переопределяют метод __str__ для более информативного вывода

## Использование
Создан класс Product, который будет иметь следующие свойства:

- название (name)
- описание (description)
- цена (price)
- количество в наличии (quantity)

Реализован класс Category. Категория будет содержать следующие свойства:

- название (name)
- описание (description)
- список товаров категории (products).

Кроме того, у класса будут дополнительные статические переменные:

- общее количество созданных категорий (category_count)
- общее количество товаров среди всех категорий (product_count)
